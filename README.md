# CareerForge

> Professional ATS Resume Builder, Job Match Analyzer, Cover Letter Generator, and LinkedIn Optimizer for Claude Code.

CareerForge is a Claude Code skill that helps users create recruiter-friendly, ATS-optimized resumes while maintaining complete honesty and accuracy.

Whether you're a student applying for internships, a software engineer targeting product-based companies, or an experienced professional planning your next career move, CareerForge provides structured, actionable guidance.

### ATS Resume Review

## Core Principles

### Truth Over Everything

CareerForge never:

* Invents experience
* Invents achievements
* Invents skills
* Invents certifications
* Invents companies
* Invents metrics

### No Keyword Stuffing

Keywords are only recommended when they genuinely align with a user's background and experience.

### ATS First

Every recommendation prioritizes:

* Recruiter readability
* ATS compatibility
* Clear structure
* Measurable impact

## ATS Scoring Framework

| Category                | Points |
| ----------------------- | ------ |
| Keyword Relevance       | 25     |
| Action Verbs            | 20     |
| Quantifiable Impact     | 20     |
| ATS Formatting & Length | 15     |
| Section Completeness    | 10     |
| Grammar & Consistency   | 10     |

**Total: 100 Points**
